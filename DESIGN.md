# EcoSort AI design system

## Direction

EcoSort is designed as an inspection passport for a busy campus or household sorting moment. The interface uses the visual language of a jet-age ticket wallet: routeable records, ruled fields, coupon-like sections, and stamped states. This replaces the generic rounded dashboard treatment with a practical, memorable operating surface.

## Visual language

- **Palette:** ink black `#20262B`, paper `#F7F8F4`, mist `#EEF1ED`, acid lime `#D7F35F` for active actions, carrier blue `#3974A8` for measurement, warning red `#E64B3C`, and ticket yellow `#E8C547`.
- **Type:** IBM Plex Sans for readable operational copy; Archivo for headings, labels, and compact uppercase metadata.
- **Surfaces:** lightly ruled paper, 10px corners, dashed ticket separators, and offset shadows that feel physical rather than glossy.
- **States:** active decisions are lime, environmental metrics are blue, contamination warnings are red, and project/support actions are yellow.

## Composition

The scanner is the primary task and occupies the left side of the desktop workspace. The current classification is a passport record beneath it, while the impact ledger and project context sit to the right. On narrow screens the columns stack in task order.

## Interaction

The first viewport supports the complete scan journey: choose an input, inspect an item, see the routing decision, then review impact. Existing camera, upload, text, preset, chat, deep-audit, drop-off, presentation, theme, and history actions remain available. Focus rings use ticket yellow for keyboard visibility.

## Quality bar

The interface must preserve readable contrast, visible focus, responsive stacking, and clear labels for every action. Motion should reinforce scanning or state changes, not decorate every section.
